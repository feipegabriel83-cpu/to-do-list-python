# Gerenciador de Tarefas em Python

Projeto simples desenvolvido em Python com foco em praticar lógica de programação, funções, listas e estruturas de repetição.

O sistema permite:

* Adicionar tarefas
* Remover tarefas
* Listar tarefas
* Navegar por um menu interativo

## Tecnologias utilizadas

* Python 3

## Conceitos praticados

* Funções (`def`)
* Listas
* `while`
* `if / elif / else`
* Manipulação de listas
* Validação de entradas
* Loops e controle de fluxo

## Melhorias futuras

* Evitar tarefas duplicadas
* Melhorar visualização da lista de tarefas
* Adicionar numeração automática nas tasks
* Criar sistema de prioridade
* Implementar validação para opções inválidas
* Permitir editar tarefas existentes

## Objetivo

Praticar programação em Python através da criação de um mini sistema de gerenciamento de tarefas via terminal.
